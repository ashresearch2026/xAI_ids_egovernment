# Explainable ML-Based Intrusion Detection for E-Government Cyber Defence

## Overview

This repository contains the source code, experimental notebooks, datasets/results, and supplementary materials associated with the research study:

**"Explainable Machine Learning-Based Intrusion Detection for e-Government Cyber Defence"**

The study investigates the use of explainable and trustworthy machine learning techniques for network intrusion detection, with emphasis on detection performance, probability calibration, and model interpretability.

## Research Objectives

The research aims to:

1. Develop machine learning-based model-selection framework for network intrusion detection.
2. Compare the performance of selected machine learning algorithms.
3. Evaluate model performance using appropriate classification metrics.
4. Assess probability calibration and prediction reliability.
5. Apply explainable AI techniques to interpret model decisions.
6. Examine the applicability of explainable and trustworthy IDS for e-government cyber defence.

## Methods

The study considers:

- Machine learning-based intrusion detection
- Performance evaluation
- Probability calibration
- Explainable AI (XAI)
- SHAP-based model interpretation
- Trustworthy machine learning
